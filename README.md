# Vicarus

*Việt Nam từ trên cao · Vietnam from above*

A new satellite view of Vietnam every time you open it: 145 hand-picked places, from the Hà Giang passes to Cà Mau Cape, Hoàng Sa and Trường Sa.

**Install on iPhone:** open the site in Safari → Share → *Add to Home Screen*.

- Swipe or use ← → for the next place, ♡ to save, ⤓ to save the view as a wallpaper
- Filter by region (North, Central, South) or theme
- Vietnamese and English
- Places you have seen still open offline

Imagery © Esri, Maxar, Earthstar Geographics. To add or adjust a place, edit `places.js`.
